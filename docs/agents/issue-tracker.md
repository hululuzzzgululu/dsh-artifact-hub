# Issue tracker: Local Markdown

Issues and specs for this repo live as markdown files in `.scratch/`.

## Conventions

- One feature per directory: `.scratch/<feature-slug>/`
- The spec is `.scratch/<feature-slug>/spec.md`
- Implementation issues are one file per ticket under `.scratch/<feature-slug>/issues/`, numbered from `01` in dependency order.
- Triage state is recorded by the `Status:` line in each issue.
- Comments and implementation notes append under a `## Comments` heading.
